### Операторы и функции для работы с датой и временем
Если PostgreSQL у вас установлен с русской локалью, запрос выше должен выполниться без проблем. Если вставлять данные из внешнего источника, строки могут не распознаться с текущими настройками СУБД: например, если формат неизвестный или не совпадает с локалью. В таких случаях пригодятся функции to_date и to_timestamp, которые позволяют в явном виде задать формат даты или даты-времени. Вот несколько примеров применения таких функций:  
```
SELECT to_date('2022-01-01', 'YYYY-MM-DD');
SELECT to_date('01/01/2022', 'MM/DD/YYYY');
SELECT to_date('01-22', 'MM-YY');
SELECT to_date('05 Dec 2000', 'DD Mon YYYY');
SELECT to_timestamp('2022-01-01 12:30:00', 'YYYY-MM-DD HH24:MI:SS');
```

Так выглядит запрос, который выведет текущую дату на экран:  
```
SELECT CURRENT_DATE;
```

А вот выражение для получения дней, прошедших с момента заказа:  
```
SELECT CURRENT_DATE - invoice_date::date
FROM invoice
LIMIT 5; 
```
Функция **DATE_TRUNC** «усекает» дату и время до необходимого значения: например, года, месяца или дня.  
Функция пригодится в случае, если нужно посчитать записи за конкретный период.  

```
DATE_TRUNC('отрезок времени', значение)

Отрезки времени:

'millennium' — тысячелетие.
'century' — век.
'decade' — десятилетие.
'year' — год.
'quarter' — квартал.
'month' — месяц.
'week' — неделя.
'day' — день.
'hour' — час.
'minute' — минута.
'second' — секунда.
'microseconds' — микросекунды.
'milliseconds' — миллисекунды.

Пример, в таблице birth_date = '1968‑02‑18 00:00:00'

SELECT DATE_TRUNC('year', birth_date)
FROM staff
LIMIT 5; 

результат birth_date = 01.01.1968 00:00:00 - округлилось до года, месяц и день сбросились до 01

SELECT DATE_TRUNC('month', birth_date)
FROM staff
LIMIT 5; 

результат birth_date = 01.02.1968 00:00:00 - округлилось до месяца, только день сбросилися до 01
```

Такое усечение не подойдёт для случаев, когда нужно получить конкретную часть даты: год, месяц или минуту. Для таких задач используют другие функции.  

Функция **DATE_PART** или её аналог **EXTRACT** выводят конкретную часть даты.  
Синтаксис DATE_PART('отрезок времени', значение) похож на DATE_TRUNC.  
У EXTRACT он немного отличается: EXTRACT(отрезок времени FROM значение).  
Одинарные кавычки для значений отрезка времени внутри EXTRACT не нужны.  

```
SELECT EXTRACT(YEAR FROM birth_date)
FROM staff
LIMIT 5; 

результат birth_date = 1968
```
