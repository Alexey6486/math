### Операторы сравнения
Для сравнения значений в PostgreSQL используют операторы:  
```
=	равно  
<>, !=	не равно  
>	больше  
<	меньше  
>=	больше или равно  
<=	меньше или равно  
```

Эти операторы применяют для сравнения чисел, строк, дат, значений времени и временных меток (timestamp).  
Ещё есть операторы для сравнения с NULL:  
IS NULL, ISNULL — значение отсутствует,  
IS NOT NULL, NOTNULL — присутствует любое значение.  

```
-- наименования товаров, количество которых больше нуля  
SELECT name FROM products WHERE amount > 0;

-- наименования и количество товаров, цена которых больше или равна 100  
SELECT name, amount FROM products WHERE price >= 100;

-- имена и дни рождения пользователей, у которых отсутствует дата удаления
SELECT name, birthday FROM users WHERE deleted_at IS NULL; 
```

### Операторы AND, OR, NOT  

Эти операторы объединяют или исключают условия:  

AND — вернёт истинное значение (true), если все условия, которые объединяет этот оператор, истинны. То есть выгружаемые данные должны соответствовать всем перечисленным условиям.  

OR — вернёт истинное значение (true), если хотя бы одно из условий, которые объединяет этот оператор, истинно. Выгружаемые данные должны соответствовать хотя бы одному из перечисленных условий.  

NOT — меняет значение логического выражения с истинного (true) на ложное (false) и наоборот. Выгружаемые данные должны не соответствовать заданному условию.  

```
-- наименования товаров, отсутствующих на складе или удалённых
SELECT name FROM products WHERE amount = 0 OR deleted_at IS NOT NULL;

-- имена и телефоны пользователей, родившихся в 1973 году
SELECT name, phone 
FROM users 
WHERE birthday >= '1973-01-01' AND birthday <= '1973-12-31';

-- наименования товаров в категориях "Средства гигиены" или "Косметика"  
SELECT name 
FROM products 
WHERE category = 'Средства гигиены' OR category = 'Косметика';

/*
наименования всех товаров, 
кроме категорий "Средства гигиены" или "Косметика"  
*/
SELECT name 
FROM products 
WHERE NOT (
    category = 'Средства гигиены' OR 
    category = 'Косметика'
);
```

В логических выражениях приоритет скобок выше приоритета операторов — как в математике. Это значит, что сначала выполняются действия в скобках, а затем остальные операторы в таком порядке:  
1. сначала NOT,  
2. затем AND,  
3. и в конце OR.

### Операторы IN, BETWEEN  
В некоторых случаях условия можно записать короче, применив операторы IN и BETWEEN:  
IN (v1, v2, … vN) — выбирает значение из списка. Значения, по которым нужно фильтровать данные, перечисляют в скобках.  
NOT IN (v1, v2, … vN) — выбирает значение, которое не соответствует списку. Список значений также перечисляют в скобках.  
BETWEEN x AND y — выбирает значение, которое равно x или y или находится в промежутке между ними.  

```
/*
наименования товаров 
в категориях "Средства гигиены" или "Косметика"
*/ 
SELECT name 
FROM products 
WHERE category IN ('Средства гигиены', 'Косметика');

/*
наименования всех товаров 
кроме категорий "Продукты питания" и "Напитки"
*/
SELECT name 
FROM products 
WHERE category NOT IN ('Продукты питания', 'Напитки');

/*
имена и телефоны пользователей, родившихся в 1973 году
*/
SELECT name, phone 
FROM users 
WHERE birthday BETWEEN '1973-01-01' AND  '1973-12-31';
```

### Операторы LIKE, ILIKE
Кроме операторов для сравнения строк, широко используют оператор поиска по шаблону LIKE. Он позволяет находить строки, которые соответствуют определённому шаблону. Чтобы задать шаблон, используют специальные символы.  

Знак процента % — показывает, какую позицию в строке занимает шаблон. Внутри шаблона может быть любое количество символов любого типа. Например:  

Шаблон '%SQL%' — найдёт строки, которые содержат слово “SQL”, где угодно внутри строки: «мы изучаем SQL», «знание SQL востребовано на рынке труда» или “SQL — Structured Query Language”.  

Шаблон 'SQL%' — найдёт строки, которые начинаются с подстроки “SQL”.  

Шаблон '%SQL' — найдёт строки, которые заканчиваются подстрокой “SQL”.  

Знак подчеркивания _ — показывает, какую позицию в слове занимает шаблон. Внутри шаблона может быть только один символ. Например, шаблон c_t найдёт строки, в которых между символами "c" и "t" находится ровно один символ, например "cat" или "cut". Строка "curt" не попадёт в выборку, так как одно подчёркивание соответствует одному знаку.  

ILIKE также ищет по шаблону, но в отличие от LIKE не учитывает прописные и строчные буквы.

```
/*
выберите товары, в описании которых
есть слово детский/ая/ое 
для поиска используйте шаблон '%детск%',
совпадающий со всеми формами слова
*/
SELECT name 
FROM products 
WHERE description LIKE '%детск%';

/*
если, наоборот, нужно найти все товары, 
кроме детских, примените
оператор NOT LIKE 
*/

SELECT name 
FROM products 
WHERE description NOT LIKE '%детск%';

SELECT name, description, price
FROM products 
WHERE name LIKE '%Кружка%' OR description LIKE '%Кружка%';

/* поиск без учета регистра */
SELECT name, description, price
FROM products 
WHERE name ILIKE '%Кружка%' OR description ILIKE '%Кружка%';
```

### Регулярные выражения

Когда подобрать шаблон для поиска нужных строк затруднительно, можно обратиться к регулярным выражениям ~.  
Общий синтаксис такой:  
```
<строка> ~ <регулярное выражение>  -- строка соответствует выражению
<строка> !~ <регулярное выражение> -- строка не соответствует выражению
```
